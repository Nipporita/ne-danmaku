Nekocast Danmaku — 前后端接口文档

元火弹幕姬核心 — 多源弹幕聚合网关，支持 Satori（QQ）、Bilibili 直播、OneBot v11 三种弹幕源，通过 WebSocket 向前端实时推送。

版本：0.1.0  |  许可证：Apache-2.0

1. 项目概述

Nekocast Danmaku 是一个独立的弹幕中继服务，从 Nekocast 主项目中提取。核心功能：

  • 多源聚合：Satori（gugugaga bot）、Bilibili 直播、OneBot v11（LLOneBot / NapCat）
  • 实时推送：WebSocket 向前端广播弹幕，支持多房间隔离
  • 文本指令：/sc 发送 SuperChat、/gift 发送礼物
  • 虚拟货币：燕火（huo）用于 SC 消费、燕元（yuan）用于礼物消费
  • 内容过滤：正则黑名单 + 去重 + 用户封禁，标记 blocked 而非丢弃
  • 动态配置：config.json 修改后自动热加载（无需重启）
技术栈：
后端 — Python 3.11+ / FastAPI / uvicorn / Pydantic / SQLAlchemy / watchdog
前端 — Vue 3 / Vite / danmaku (weizhenye/danmaku) / pnpm
弹幕源 — Satori Python SDK / blivedm / aiocqhttp

4. HTTP API

所有 API 的基础路径：/api/danmaku/v1

4.1 公开配置

方法路径鉴权说明
GET / 无 健康检查
GET /config 无 公开配置（前端读取字数上限等） 
// GET /api/danmaku/v1/config 响应
{
  "max_message_length": 50,
  "config_version": 3
}

4.2 余额查询（无需鉴权）

方法路径参数说明
GET /balance ?username= 按用户名查余额
GET /balance_by_id ?user_id= 按用户 ID 查余额

4.3 房间设置（需 admin token）

方法路径说明
GET /admin/rooms/{group}/settings?token= 读取房间设置
PUT /admin/rooms/{group}/settings?token= 更新房间设置
POST /admin/rooms/{group}/clear?token= 清空房间弹幕/SC/礼物覆盖层 
// 房间设置 JSON 结构
{
  "overlay_opacity": 100.0,        // 弹幕透明度 0-100
  "enable_external_emoji": true,   // 外部表情（Satori/OneBot）
  "enable_internal_emoji": true,   // 内部表情（【表情】文本）
  "enable_superchat": true,        // SuperChat 显示
  "enable_gift": true,             // 礼物显示
  "bind_position": true            // 允许置顶/置底定位
}

4.4 运行时配置管理（需 admin token）

方法路径说明
GET /admin/config?token= 查看当前运行配置（脱敏）
PUT /admin/config?token=&persist=true 运行时更新可热加载字段 
// PUT /api/danmaku/v1/admin/config?token=xxx
// 只传要更新的字段（dotted path），persist=true 写回文件
{
  "max_message_length": 100,
  "superchat": { "default_cost": 5.0 },
  "cash.initial_huo": 200.0
}
// 响应
{ "ok": true, "changes": ["max_message_length", "superchat", "cash.initial_huo"], "persisted": true }

4.5 审核管理（需 admin token）

方法路径参数说明
POST/admin/rooms/append_pattern?pattern=&hard=添加黑名单正则
POST/admin/rooms/remove_pattern?pattern=&hard=删除黑名单正则
GET/admin/rooms/list_patterns列出所有黑名单正则
POST/admin/rooms/ban_user?user_id=封禁用户
POST/admin/rooms/unban_user?user_id=解封用户
GET/admin/rooms/list_banned_users列出所有封禁用户

4.6 充值管理（需 admin token）

方法路径说明
GET/admin/rooms/{group}/users?token=列出房间用户及余额
POST/admin/rooms/{group}/charge/{user_id}?token=为指定用户充值（body: {currency, amount}）
POST/admin/rooms/{group}/charge_all?token=为全房间用户充值

4.7 表情管理

方法路径鉴权说明
GET/api/danmaku/v1/emotes无列出可用表情包
GET/api/emoji/{key}无Emoji 缓存代理

5. WebSocket 协议

5.1 客户端连接（观众端）

端点ws://host:port/api/danmaku/v1/danmaku/{group}
方向服务器 → 客户端（只推送）
鉴权无需 token

客户端发送的任何消息都会被忽略。服务器单向推送弹幕 JSON。

5.2 上游连接（管理端）

端点ws://host:port/api/danmaku/v1/upstream?token={token}
方向双向
鉴权需要 config.danmaku.upstream.token

上游发送弹幕数据包到服务器，服务器处理后广播到指定房间的所有客户端。

5.3 弹幕消息类型（服务器 → 客户端 JSON）

所有消息继承 DanmakuBase 公共字段：

{
  "type": "消息类型",
  "senderId": "发送者唯一ID | null",
  "sender": "发送者昵称 | null",
  "is_special": false,
  "blocked": false         // 是否被黑名单/去重标记
}

PlainDanmakuMessage — 普通弹幕

{
  "type": "plain",
  "text": "弹幕文本内容",
  "color": "#ffffff | null",       // CSS 颜色
  "size": 40 | null,               // 字号 px
  "position": "scroll",            // "scroll" | "top" | "bottom"
  "senderId": "...", "sender": "...",
  "is_special": false, "blocked": false
}

EmoteMessage — 单表情

{
  "type": "emote",
  "emote_url": "/api/emoji/xxx 或 https://...",
  "senderId": "...", "sender": "...",
  "is_special": false, "blocked": false
}

MultiEmoteMessage — 多表情（内置表情解析）

{
  "type": "multi_emote",
  "emote_urls": ["url1", "url2", ...],
  "senderId": "...", "sender": "...",
  "is_special": false, "blocked": false
}

SuperChatMessage — 醒目留言

{
  "type": "superchat",
  "text": "SC 文本内容",
  "cost": 10.0,                    // 花费的燕火
  "duration": 10,                  // 展示时长（秒）
  "avatar_url": "/api/emoji/xxx | null",
  "senderId": "...", "sender": "...",
  "is_special": false, "blocked": false
}

GiftMessage — 礼物

{
  "type": "gift",
  "gift_name": "onigiri",          // 礼物名称
  "quantity": 1,                   // 数量
  "cost": 1.0,                     // 总价（燕元）
  "image_url": "/assets/gifts/饭团.png | null",
  "avatar_url": "/api/emoji/xxx | null",
  "senderId": "...", "sender": "...",
  "is_special": false, "blocked": false
}

5.4 控制消息（服务器 → 客户端）

// 房间设置同步
{ "type": "settings", "settings": { "overlay_opacity": 100.0, ... } }

// 清空指令
{ "type": "control", "action": "clear_all" }

5.5 上游发送格式（管理端 → 服务器）

// 格式 A：完整带 type（Pydantic 直接解析）
{
  "group": "房间名",
  "danmaku": {
    "type": "plain",
    "text": "弹幕内容",
    "color": "#ffffff",
    "sender": "元火子"
  }
}

// 格式 B：扁平格式（自动解析 /sc、/gift、颜色、位置命令）
{
  "group": "房间名",
  "danmaku": {
    "text": "/sc 10 这是一条 SC",   // 自动识别 /sc 前缀
    "sender": "元火子"
  }
}

// 格式 B 中的文本指令：
//   /sc [cost] 文本         → SuperChatMessage
//   /gift 礼物名 [数量]      → GiftMessage
//   /置顶 文本 或 /置底 文本 → position: "top"/"bottom"
//   #ff0000 文本            → color: "#ff0000"

上游发送的每条弹幕都会被自动标记 "is_special": true 并追加 👑 标识。

6. 前端组件

6.1 DanmakuDisplay（观众端弹幕层）

路由/danmaku/{房间名}
用途OBS 直播叠加层，全屏透明背景
渲染库danmaku (weizhenye/danmaku v2.0.9)，DOM 引擎

处理流程：

WebSocket onmessage
  → type="settings" → 更新透明度/开关
  → type="control"  → clear_all（销毁并重建 danmaku 实例）
  → 其他            → sendMessage(data)
      → type="plain"        → danmaku.emit({mode, text, style})
      → type="emote"/"multi" → AssetManager 加载图片 → danmaku.emit({render: img})
      → type="superchat"    → SuperChatDisplay 组件
      → type="gift"         → GiftDisplay 组件
      → msg.blocked === true → 跳过渲染

6.2 ChatClient（管理端控制台）

路由/danmaku/chat/{房间名}?key={token}
用途发送弹幕、管理房间设置、审核、充值
连接同时连接客户端 WS + 上游 WS（需要 token）

功能模块：

  • 弹幕发送：输入框支持文本指令（/sc、/gift、颜色、位置）
  • 房间设置：透明度滑块、表情/SC/礼物开关、置顶置底开关
  • 充值管理：按用户充值燕火/燕元，全房间充值
  • 审核面板：封禁/解封用户，管理黑名单正则，正则测试
  • Blocked 标记：收到 blocked: true 的消息显示红色 BLOCKED 徽章

6.3 SuperChat / Gift 显示组件

SuperChatDisplay.vue — 固定位置叠加层，按金额排序显示 SC 卡片，duration 秒后自动移除。

GiftDisplay.vue — 礼物动画叠加层，显示礼物图片 × 数量 + 总价。

两个组件均使用 uuid 库生成唯一 ID（替代 crypto.randomUUID() 以兼容非 HTTPS 环境）。

7. 游戏服务器集成

7.1 blocked 标记机制

核心原则：后端绝不丢弃任何消息。即使消息命中黑名单、发送者被封禁、或触发去重，消息都会被完整广播到所有 WebSocket 客户端。后端仅在消息上设置 "blocked": true 标记。

触发条件文本处理blocked消息类型
发送者 ID 在封禁列表 保留原文 true 所有类型
文本命中黑名单正则 保留原文 true PlainDanmaku
SC 文本命中黑名单 打码（***） false SuperChat
SC/Gift 昵称命中黑名单 打码（***） false SuperChat / Gift
短时重复弹幕（去重） 保留原文 true PlainDanmaku
文本超过字数上限 截断到 max_message_length false PlainDanmaku / SC

游戏服务器集成指南：游戏服务器应连接客户端 WebSocket，接收所有消息（包括 blocked: true 的）。游戏逻辑不受 blocked 影响——该标记仅供弹幕展示层使用。原始文本完整保留，游戏指令和玩家消息不受损。

游戏服务器应建议使用 WS URL：ws://host:port/api/danmaku/v1/danmaku/{游戏房间名}

7.2 轻量模拟服务器 (danmaku-server)

位于 danmaku-app/danmaku-server/server.py，基于 Python tkinter + websockets，用于游戏开发测试。发送的消息格式应兼容实际后端。详见 danmaku-app 项目。
